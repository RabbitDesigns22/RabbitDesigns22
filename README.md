## Cómo trabajo

Desde mi casa manejo una agencia completa con **más de 15 chats de Claude trabajando a la vez**:

- un chat por cliente, que diseña sus posts, historias y videos para Meta Ads;
- un **Supervisor** que reparte el trabajo y revisa cada pieza antes de que salga;
- un **Planificador** que programa todo en Facebook e Instagram;
- chats para páginas web, Google Ads, apps y estudio de cada nicho;
- tareas que corren solas de madrugada, y un asistente por Telegram con voz.

Yo hablo con uno. Ellos se coordinan entre sí.

## Skills que comparto

Lo que me sirvió a mí, abierto para que lo uses en tu Claude Code:

| Skill | Para qué sirve |
|---|---|
| [**one-pass**](https://github.com/RabbitDesigns22/one-pass) | Que Claude haga las cosas bien a la primera y no gaste tokens rehaciendo trabajo. |
| [**hora-exacta**](https://github.com/RabbitDesigns22/hora-exacta) | Que cada chat sepa la fecha y la hora reales (CDMX, Lima, Costa Rica, Caracas, Florida) en vez de adivinarlas. |

```bash
npx skills add RabbitDesigns22/one-pass -g -y
npx skills add RabbitDesigns22/hora-exacta -g -y
```
